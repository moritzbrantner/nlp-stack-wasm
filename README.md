# nlp-stack-wasm

Git-installable distribution of the `text-core-wasm` and `text-index-wasm` WASM packages from
[moritzbrantner/nlp-stack](https://github.com/moritzbrantner/nlp-stack).

The repository root is the package. Consumers pin it by commit; it is never published to npm.
See moritzbrantner/document-search#18 for the owner decision.
